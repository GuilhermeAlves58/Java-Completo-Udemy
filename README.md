# ☕ Java COMPLETO: Programação Orientada a Objetos + Projetos

Este repositório reúne todos os projetos desenvolvidos durante o curso **Java COMPLETO - Programação Orientada a Objetos + Projetos**, ministrado pelo professor **Dr. Nélio Alves** na [Udemy](https://www.udemy.com/course/java-curso-completo/).

📌 O objetivo é documentar minha jornada de aprendizado em Java, passando pelos fundamentos da linguagem até aplicações mais avançadas, incluindo **acesso a banco de dados**, **web services**, **interfaces gráficas**, **projetos com frameworks modernos** e **integração com diferentes tecnologias**.

Este repositório também funciona como um **portfólio de estudos**, atualizado continuamente à medida que novos módulos do curso forem concluídos.

## 🧪 Projetos Desenvolvidos

### 🔗 [Acesso a Banco de Dados com JDBC](https://github.com/GuilhermeAlves58/Acesso-banco-de-DadosJDBC-Projeto-)
Demonstração prática de acesso a banco de dados com JDBC, incluindo estrutura de projeto com DAO e transações SQL.

### ♟️ [Jogo de Xadrez](https://github.com/GuilhermeAlves58/Chess-Project)
Projeto completo de um jogo de xadrez em console, aplicando conceitos de **POO** (herança, polimorfismo, abstração, exceções).  
Inclui regras oficiais como **Xeque, Xeque-mate, Roque, En Passant e Promoção de Peão**.

### 🍃 [Web Services com Spring Boot + MongoDB](https://github.com/GuilhermeAlves58/WebServiceMongoDB)
Projeto de API REST utilizando **Spring Boot** com **MongoDB** como banco de dados orientado a documentos.  
Inclui CRUD de usuários e posts, associação de documentos, comentários, consultas personalizadas e uso de **DTOs**.

### 🌐 [Web Services com Spring Boot + JPA/Hibernate](https://github.com/GuilhermeAlves58/Web-Service-Spring-Boot-JPA-Hibernate)
Projeto de web services REST com **Spring Boot** e **JPA/Hibernate** para mapeamento objeto-relacional.  
Inclui CRUD completo, tratamento de exceções e configuração com banco de dados H2 (teste) e PostgreSQL (produção).

### 🖼️ [Interface Gráfica com JavaFX](https://github.com/GuilhermeAlves58/JavaFX)
Projeto de interface gráfica utilizando **JavaFX**, aplicando conceitos de orientação a eventos e construção de UIs modernas em Java. *(em desenvolvimento)*

## 📖 Sobre o Curso

O curso aborda desde os fundamentos da linguagem Java até tópicos avançados, como:

- Programação Orientada a Objetos (POO)
- Estruturas de dados e coleções
- Tratamento de exceções
- Acesso a banco de dados com JDBC
- JPA/Hibernate e integração com bancos relacionais
- Web Services REST com Spring Boot
- MongoDB e bancos orientados a documentos
- Interface gráfica com JavaFX
- Boas práticas, design patterns e princípios de clean code
